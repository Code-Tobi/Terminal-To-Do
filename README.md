# Terminal To-Do
A simple to-do app that runs in the terminal
## How the program works
* **Add a to-do:** Enter the command “add” followed by the name of the to-do
* **Delete a to-do:** Enter the command “delete” followed by the number of the to-do
* **Check and uncheck a checkbox:** To change the status of the checkbox, enter the command “checkbox” followed by the to-do number
